# 🧠 SKILLS

我的 Claude Skill 收藏库。每个 Skill 是一段让 Claude 掌握特定工作流的指令文件，可直接安装到 Claude.ai 使用。

## 📦 安装方式

下载对应文件夹中的 `.skill` 文件（或直接使用 `SKILL.md`），在 Claude.ai 设置页面中安装。
